# Review standards

Reviewers enforce the repository rules in [AGENTS.md](AGENTS.md) and [CONTRIBUTING.md](CONTRIBUTING.md). Mechanical checks (banned dashes, relative markdown links, repository fact consistency, working-tree cleanliness, and pytest suites) run in [scripts/check.sh](scripts/check.sh). This file holds judgement rules learned from past review rounds.

## Judgement checks

1. **Check new policy wording against existing authority documents.** When a change adds or edits a repository rule, verify it does not contradict existing decisions or governance docs. *Incident:* in PR #13, commit `1acf103` introduced a blanket rule against real people names in `AGENTS.md` that conflicted with existing governance references to the repository owner in `CONTRIBUTING.md` and `docs/decisions.md`; commit `f8e099d` corrected the boundary.
2. **Test adversarial boundaries on every new check or validator.** Do not accept happy-path coverage alone. Ask what input could pass vacuously, escape the repository boundary, or bypass a parser. *Incident:* in PR #14, commit `6931857` swallowed `FileNotFoundError` on missing tracked paths, used a link regex that missed balanced parentheses and reference definitions, and limited markdown scanning to three directories; commit `8d2dbf1` fixed those gaps, and commit `43380b2` closed a symlink-escape gap in `8d2dbf1`'s markdown discovery.
3. **Check invariants against an independent source.** Comparing two files that can drift together hides paired deletions or compensating edits. Verify that checks pin full claims against an independent source (such as `docs/decisions.md` citations or pinned counts). *Incident:* in PR #15, commit `7616173` compared `docs/spikes/` with `spikes/` without an independent source (hiding paired deletions) and summed work requests to 200 without pinning category or class counts; commit `bab3907` added the independent checks.
4. **State formal and property rules in their own words.** A rule that reuses a constant or helper from the code under test can let seeded bugs slip through. Check that Quint invariants, SHACL expectations, and Hypothesis properties assert independent behavior. *Incident:* as recorded in [docs/verification.md](docs/verification.md) section 4, during PR #10 (squash-merged as `6b7e881`) a seeded bug passed a Quint rule that read the same constant as the code and review tightened `NothingMissed` and `FreezeIsExact`; separately, during PR #12 (squash-merged as `37cc67e`), review added a sixth write-through seeded bug and the nonnegative-target clause to `WorkflowOnly`.

# Review standards

Reviewers enforce the repository rules in [AGENTS.md](AGENTS.md) and [CONTRIBUTING.md](CONTRIBUTING.md). Mechanical checks (banned dashes, relative markdown links, repository fact consistency, working-tree cleanliness, and pytest suites) run in [scripts/check.sh](scripts/check.sh). This file holds judgement rules learned from past review rounds.

## Judgement checks

1. **Check new policy wording against existing authority documents.** When a change adds or edits a repository rule, verify it does not contradict existing decisions or governance docs. *Incident:* in PR #13 (`f8e099d`), an initial blanket rule against real people names in `AGENTS.md` conflicted with existing governance references to the repository owner in `CONTRIBUTING.md` and `docs/decisions.md`.
2. **Test adversarial boundaries on every new check or validator.** Do not accept happy-path coverage alone. Ask what input could pass vacuously, escape the repository boundary, or bypass a parser. *Incident:* in PR #14 (`8d2dbf1`, `43380b2`), review caught swallowed `FileNotFoundError` on missing tracked paths, a link regex that missed balanced parentheses and reference definitions, and symlinked markdown files pointing outside the checkout.
3. **Check invariants against an independent source.** Comparing two files that can drift together hides paired deletions or compensating edits. Verify that checks pin full claims against an independent source (such as `docs/decisions.md` citations or pinned counts). *Incident:* in PR #15 (`bab3907`), comparing `docs/spikes/` with `spikes/` missed deleting both together, and summing work requests to 200 missed dropping a category while raising another.
4. **State formal and property rules in their own words.** A rule that reuses a constant or helper from the code under test can let seeded bugs slip through. Check that Quint invariants, SHACL expectations, and Hypothesis properties assert independent behavior. *Incident:* in PR #10 (`6b7e881`) and PR #12 (`37cc67e`, documented in [docs/verification.md](docs/verification.md) section 4), a seeded bug passed a Quint rule that read the same constant as the code, and review tightened `NothingMissed`, `FreezeIsExact`, and the nonnegative-target rule.
